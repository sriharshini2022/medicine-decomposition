
# 🌿 Eco-Friendly Medicine Disposal Advisor

A Streamlit-powered AI application that helps users dispose of medicines in an environmentally safe and responsible way. The app uses Google's Gemini (Generative AI) model to provide expert-level disposal guidance based on the entered medicine name.

---

## 📌 Project Inspiration

This project was conceived on **19 May 2024**, during a community service initiative. As an AI/ML student, I realized the need for better awareness around eco-friendly medicine disposal and saw an opportunity to use generative AI to assist everyday users in making environmentally responsible decisions.

---

## 🚀 Features

- ✅ Simple Streamlit UI
- 🤖 Powered by **Google Gemini** for accurate, AI-generated disposal recommendations
- 🌱 Promotes environmental sustainability by avoiding harmful disposal practices
- 🧪 Identifies active ingredients and explains proper disposal methods
- 📚 Educational and user-friendly output for the general public

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit** – for the web interface
- **Google Generative AI (Gemini)** – for AI-based responses

---

## 🧑‍💻 How It Works

1. User enters a medicine name.
2. The app prompts Gemini to:
   - Identify common active ingredients.
   - Suggest safe and eco-conscious disposal methods.
3. The result is displayed in an easy-to-understand format.

---

## 🔧 Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/eco-disposal-advisor.git
   cd eco-disposal-advisor
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Set your Google API key**
   Replace the API key in the script with your own from [Google AI Studio](https://makersuite.google.com/).

4. **Run the app**
   ```bash
   streamlit run app.py
   ```
